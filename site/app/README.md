# A14 实际界面静态版

此目录使用项目原始 `frontend/index.html` 与本地 Vue、Element Plus、ECharts 文件，布局和页面模板直接来自项目本身。`static-demo-adapter.js` 提供浏览器内的演示数据，不请求项目后端。

打开 `index.html` 可浏览工作台、数据集、知识库、预处理分析、Agent 工作台、分析报告、算法模板、用户和审计等原有界面。部分上传、计算和外部问答功能仅作界面展示。

GitHub Pages 在线版：<https://1eric812.github.io/a14-agent-showcase/app/>
访客可直接打开演示页面，无需账号或密码；默认进入工作台。
